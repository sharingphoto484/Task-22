FLEET OPERATIONS ANALYSIS QUALITY CONTROL NOTES

PROMPT GOAL

The analysis objective is to optimize fleet utilization reduce maintenance expenses and maximize customer profitability through ten sophisticated machine learning and statistical analyses across three Excel datasets containing customer accounts driver monthly performance metrics and maintenance event records. The project implements Support Vector Machine classification Polynomial Regression K Nearest Neighbors regression Exponential Smoothing time series forecasting and Gaussian Mixture Model clustering alongside descriptive analytics for facility performance freight type segmentation driver improvement tracking maintenance cost ratios and fuel efficiency correlation assessment. The datasets comprise two hundred customer accounts with contract details one hundred twenty four unique drivers tracked across thirty six months from January 2022 through December 2024 and two thousand nine hundred twenty maintenance events across one hundred twenty trucks at multiple facility locations. Machine learning models require specific train test split ratios random seeds kernel specifications polynomial degrees smoothing parameters and clustering components while generating five publication quality visualizations including scatter plots fitted curves actual versus predicted comparisons time series forecasts and three dimensional cluster representations. The deliverable provides actionable insights enabling data driven decisions on driver retention maintenance scheduling customer prioritization cost optimization and operational efficiency improvements.

STEP BY STEP SOLUTIONS

Step 1: The analysis begins by loading three Excel format datasets using pandas library where customers file contains two hundred records with eight columns including customer identifier name type credit terms freight type account status contract date and annual revenue potential. The driver monthly metrics file contains performance data for one hundred twenty four unique drivers across thirty six months with nine columns capturing driver identifier month trips completed total miles revenue average miles per gallon fuel consumption on time delivery rate and idle hours. The maintenance records file contains two thousand nine hundred twenty maintenance events with twelve columns including maintenance identifier truck identifier date type odometer reading labor metrics parts cost total cost facility location downtime hours and service description.

Step 2: The Support Vector Machine classification task starts by aggregating driver monthly metrics where for each of the one hundred twenty four unique drivers the system computes mean on time delivery rate by averaging across all their monthly observations mean average miles per gallon by averaging fuel efficiency metrics total trips completed by summing all trips and total miles by summing mileage across the entire thirty six month period. This aggregation transforms the original driver month level dataset with four thousand four hundred sixty four observations into a driver level dataset with one hundred twenty four observations where each row represents one driver comprehensive performance profile. The aggregated features serve as both predictive variables and the basis for creating the binary classification target variable.

Step 3: The binary target variable for SVM classification is created by applying a threshold of zero point five to the mean on time delivery rate where drivers meeting or exceeding this threshold are encoded as one representing high performers while drivers below the threshold are encoded as zero representing standard performers. However examination of the actual data reveals only one driver out of one hundred twenty four achieves mean on time delivery rate greater than or equal to zero point five creating extreme class imbalance with one hundred twenty three observations in class zero and only one observation in class one. This severe imbalance makes stratified sampling infeasible because stratification requires at least two samples per class in both training and testing sets.

Step 4: The feature matrix for SVM classification includes four predictor variables specifically mean on time delivery rate mean average miles per gallon total trips completed and total miles where all four aggregated metrics serve as input features despite mean on time delivery rate also being the basis for the target variable creation. The dataset is split into training and testing sets using a seventy thirty ratio where seventy percent of the one hundred twenty four drivers go to training yielding eighty six training samples and thirty percent go to testing yielding thirty eight testing samples. The split uses random state twenty five for reproducibility but crucially omits stratification parameter due to the class imbalance issue enabling the split to proceed without error.

Step 5: The Support Vector Machine model is instantiated with radial basis function kernel which enables nonlinear decision boundaries by mapping the input features into a higher dimensional space where linear separation becomes possible. The model is trained on the eighty six driver training set where the RBF kernel computes similarity between samples based on Gaussian distance allowing the SVM to learn complex patterns in driver performance characteristics. Model training with random state twenty five ensures reproducible results where the optimization algorithm finds support vectors that define the maximum margin hyperplane separating high performers from standard performers.

Step 6: After training the SVM model predictions are generated for the thirty eight driver test set and classification accuracy is computed by comparing predicted class labels against actual target values achieving perfect accuracy of one point zero. This perfect score occurs because the test set by random chance contains only class zero observations so predicting all zeros yields one hundred percent accuracy despite not being a meaningful performance indicator. The result highlights how extreme class imbalance combined with small sample size can produce misleadingly optimistic metrics that do not reflect true model generalization capability.

Step 7: The SVM visualization generates a two dimensional scatter plot where the horizontal axis represents mean on time delivery rate ranging from approximately zero point three seven to zero point five one and the vertical axis represents mean average miles per gallon ranging across driver efficiency values. Each of the one hundred twenty four points represents one driver colored according to predicted class labels from the trained SVM model using coolwarm color map where blue indicates predicted class zero and red indicates predicted class one. The visualization includes black edge colors for point visibility a color bar legend for class interpretation axis labels with twelve point font size a bold fourteen point title grid lines for readability and is saved as high resolution three hundred DPI PNG file.

Step 8: The Polynomial Regression analysis begins by filtering the maintenance records dataset to retain only rows where maintenance type equals Preventive excluding Repair type events to focus specifically on scheduled planned maintenance rather than emergency breakdowns. This filtering reduces the dataset from two thousand nine hundred twenty total maintenance events to a subset containing only preventive maintenance observations. The filtered dataset isolates the relationship between vehicle odometer reading and maintenance cost for preventive services enabling analysis of how maintenance expenses scale with vehicle usage.

Step 9: For polynomial regression the independent variable is odometer reading measured in miles representing cumulative vehicle usage at the time of maintenance while the dependent variable is total cost measured in dollars representing the complete expense including labor and parts for that maintenance event. The preventive maintenance dataset is split into training and testing sets using an eighty five fifteen ratio where eighty five percent of observations are used for model fitting and fifteen percent are held out for evaluation. Random state thirty ensures reproducible splitting enabling consistent model evaluation across multiple runs.

Step 10: Polynomial features of degree three are constructed from the single odometer reading variable creating additional squared and cubed terms along with the constant intercept term resulting in a four column feature matrix including constant linear quadratic and cubic terms. The polynomial transformation enables the linear regression model to fit nonlinear cubic relationships between odometer reading and maintenance cost capturing potential scenarios where costs increase at accelerating rates as vehicles age. A standard linear regression model is then fitted to the transformed training features learning coefficients for the intercept linear quadratic and cubic terms.

Step 11: The trained polynomial regression model generates predictions on the transformed test set features and model performance is evaluated using coefficient of determination R squared which measures the proportion of variance in total cost explained by the cubic polynomial model. The test set R squared value is negative zero point zero two two two indicating the model explains essentially none of the variance and actually performs slightly worse than simply predicting the mean cost for all observations. This poor performance suggests preventive maintenance costs do not follow a consistent polynomial pattern with odometer readings likely due to high variability in service types parts required and facility pricing.

Step 12: The polynomial regression visualization displays actual test set observations as blue scatter points with black edges where horizontal axis shows odometer reading in miles and vertical axis shows total cost in dollars creating a cloud of points revealing the true cost distribution. A red fitted curve is overlaid representing the degree three polynomial prediction computed across three hundred evenly spaced odometer values spanning the full range enabling visualization of the cubic relationship learned by the model. The plot includes twelve point font axis labels a bold fourteen point title legend distinguishing actual data from fitted curve grid lines for reference and is saved as high resolution PNG providing stakeholders a visual assessment of model fit quality.

Step 13: The K Nearest Neighbors regression task combines driver and customer datasets requiring first the aggregation of driver monthly metrics by extracting year month period from the month column then summing total revenue across all drivers for each month creating thirty six monthly revenue totals. Customer features are engineered by calculating monthly contribution as annual revenue potential divided by twelve and creating binary indicator variables where customer type equals Dedicated is encoded as one otherwise zero and account status equals Active is encoded as one otherwise zero. A cross join operation creates monthly customer records by pairing every unique year month with every customer generating a large dataset where each row represents one customer in one specific month.

Step 14: The monthly customer records are merged with the monthly driver revenue aggregates on the year month key creating a combined dataset where each customer month observation is associated with the total fleet revenue for that month regardless of individual customer contribution. This merge structure means all customers in the same month share identical target values but have different feature values based on their credit terms and categorical indicators. The predictor features are credit terms days measured as an integer and the two binary indicators for dedicated customer type and active account status while the target variable is monthly total driver revenue.

Step 15: The merged dataset for KNN regression is split into seventy five percent training and twenty five percent testing using random state forty ensuring reproducible evaluation where the training set is used to fit the K Nearest Neighbors regressor with seven neighbors. The KNN model predicts revenue for test set observations by finding the seven nearest training samples based on Euclidean distance in the three dimensional feature space then averaging their target revenue values. Model performance is evaluated using mean squared error on the test set yielding fifty eight billion seven hundred two million four hundred nine thousand four hundred fifty one point four three indicating very large prediction errors due to the weak relationship between individual customer attributes and aggregate fleet revenue.

Step 16: The KNN regression visualization creates an actual versus predicted scatter plot where horizontal axis displays actual monthly revenue values from the test set and vertical axis shows corresponding predicted values from the trained KNN model with points colored green and black edges for visibility. A red dashed diagonal reference line is overlaid representing perfect predictions where actual equals predicted enabling visual assessment of prediction quality by observing point distances from this line. The extremely high mean squared error manifests visually as substantial scatter around the diagonal with points deviating far from the perfect prediction line confirming the model struggles to accurately predict aggregate fleet revenue from customer level features.

Step 17: The Exponential Smoothing analysis begins by aggregating maintenance records to monthly level by extracting year month period from maintenance date then summing total cost across all maintenance events within each month creating a time series with thirty six observations spanning January 2022 through December 2024. The monthly aggregates are sorted chronologically ensuring proper temporal ordering required for time series modeling. A timestamp column is created by converting period objects to timestamp format enabling proper datetime axis formatting in visualizations.

Step 18: Simple Exponential Smoothing is applied to the thirty six monthly cost observations with smoothing parameter alpha set to zero point three meaning the model assigns thirty percent weight to the most recent observation and seventy percent weight to the exponentially weighted average of all prior observations. The model is fitted with optimized parameter set to false ensuring the specified alpha value of zero point three is used exactly rather than estimating alpha from the data. After fitting the model generates forecasts for six months beyond December 2024 spanning January 2025 through June 2025 where each forecast represents predicted monthly maintenance expenditure.

Step 19: The sixth month ahead forecast predicts one hundred fifty six thousand one hundred thirty four dollars and fifty cents for June 2025 maintenance costs where this value represents the model expectation based on exponentially smoothed historical patterns. Because simple exponential smoothing with fixed alpha produces flat forecasts the predicted values for all six future months are essentially identical converging to the smoothed level. The exponential smoothing visualization displays historical actual costs as a solid blue line with circular markers and the six month forecast as an orange dashed line with square markers where horizontal axis spans January 2022 through June 2025 and vertical axis shows monthly cost in dollars enabling operations managers to compare historical patterns against future projections for budget planning.

Step 20: The Gaussian Mixture Model clustering analysis aggregates driver monthly metrics to driver level by computing mean average miles per gallon mean on time delivery rate and mean average idle hours across all months for each of the one hundred twenty four drivers creating three performance profile features. These three aggregated features are standardized to zero mean and unit variance using standard scaler transformation ensuring each feature contributes equally to the clustering algorithm regardless of original measurement scale. Standardization is critical for GMM because features with larger variance would otherwise dominate the distance and covariance calculations biasing cluster formation toward those dimensions.

Step 21: A Gaussian Mixture Model with four components is fitted to the standardized three dimensional feature space using full covariance type which allows each cluster to have its own arbitrary ellipsoidal shape and orientation capturing complex correlations between fuel efficiency delivery reliability and idle time. Random state fifteen ensures reproducible cluster initialization and convergence where the expectation maximization algorithm iteratively refines cluster parameters until convergence. After fitting cluster assignments from zero to three are predicted for all one hundred twenty four drivers where each driver is assigned to the cluster with highest posterior probability given their standardized feature values.

Step 22: Cluster performance is evaluated by grouping drivers by their assigned cluster label and computing mean on time delivery rate for each cluster where cluster three achieves the highest average of zero point four six two three identifying this as the most reliable driver performance profile. The GMM clustering visualization creates a three dimensional scatter plot with mean average miles per gallon on horizontal axis mean on time delivery rate on depth axis and mean average idle hours on vertical axis where each point represents one driver colored by cluster assignment using viridis color scheme. This multidimensional representation reveals natural groupings where cluster three drivers exhibit superior delivery reliability enabling targeted management strategies such as recognition programs or best practice documentation.

Step 23: The facility downtime analysis groups all two thousand nine hundred twenty maintenance records by facility location field then computes arithmetic mean of downtime hours for each facility identifying operational efficiency differences across locations. Los Angeles facility is identified as having maximum average downtime of twenty six point five nine hours per maintenance event substantially higher than other facilities indicating potential issues with parts inventory technician availability equipment capacity or repair complexity. This metric provides actionable intelligence for operations management to investigate Los Angeles facility processes and implement improvements such as enhanced inventory management additional training or workflow optimization to reduce vehicle downtime.

Step 24: The freight type revenue analysis groups all two hundred customer records by primary freight type field then sums annual revenue potential within each category identifying which freight segments generate maximum business value. Food and Beverage freight type emerges as the highest revenue segment with total annual revenue potential of one hundred eight million seven hundred eighty seven thousand seven hundred sixty six dollars representing the largest single market opportunity. Step 25: The driver improvement analysis computes linear trend slopes for each driver by sorting their monthly records chronologically encoding month as sequential integer indices from one to total months then fitting simple linear regression with month index as predictor and on time delivery rate as response variable. The slope coefficient represents rate of change in delivery performance per month where positive slopes indicate improvement negative slopes indicate degradation and slopes near zero indicate stable performance. Driver DRV00127 achieves maximum positive slope of zero point zero zero five two three eight indicating approximately zero point five percentage point improvement in on time delivery rate per month suggesting this driver has successfully adapted to operational requirements through experience route familiarity or effective response to coaching.

Step 26: The maintenance cost ratio analysis filters maintenance records into two categories where maintenance type equals Repair represents emergency unplanned maintenance and maintenance type equals Preventive represents scheduled planned maintenance then sums total cost within each category. Emergency repair costs total nine hundred forty five thousand three hundred seventy five dollars and forty four cents while preventive maintenance costs total nine hundred sixty three thousand five hundred seventy six dollars and thirty four cents yielding a ratio of zero point nine eight one one. This ratio indicates emergency repairs cost ninety eight percent as much as preventive maintenance suggesting reasonable fleet health but also revealing opportunities to further shift resources toward preventive programs using predictive maintenance technologies to reduce costly emergency breakdowns.

Step 27: The Spearman correlation analysis computes rank based correlation coefficient between average miles per gallon and average idle hours using all four thousand four hundred sixty four driver month observations rather than aggregated driver level data to maximize statistical power. The Spearman method assesses monotonic relationships by ranking both variables independently then computing Pearson correlation on the ranks making it robust to outliers and capable of detecting nonlinear monotonic patterns. The resulting correlation coefficient is negative zero point zero one two one with p value zero point four one nine indicating a very weak negative correlation that fails to achieve statistical significance at conventional alpha levels suggesting idle hours do not meaningfully predict fuel efficiency degradation in this fleet context potentially because other factors such as driving speed route characteristics load weight or vehicle condition exert stronger influences on miles per gallon performance.
