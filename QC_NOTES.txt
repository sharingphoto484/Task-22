COLLEGE BASKETBALL TOURNAMENT PREDICTION ANALYSIS

PROMPT GOAL

The analysis performs comprehensive machine learning on three college basketball datasets from 2013 to 2015 seasons containing team performance metrics including offensive efficiency, defensive efficiency, tempo, and tournament outcomes. The objective is to implement eleven distinct analytical techniques ranging from stepwise regression for feature selection to ensemble classification for postseason advancement prediction. Each analysis targets specific research questions such as identifying optimal predictors for power ratings, classifying tournament qualification, discovering performance tiers through clustering, and predicting conference strength categories. The methods include both supervised learning approaches like support vector machines and logistic regression as well as unsupervised techniques like density based clustering. The ultimate goal is to optimize team evaluation frameworks and improve tournament bracket prediction accuracy through multi faceted statistical and machine learning approaches.

STEP BY STEP SOLUTION

Step 1: The analysis begins by loading three Excel files containing college basketball data from 2013, 2014, and 2015 seasons using pandas read excel function. Each dataset contains 347 to 351 teams with 23 columns including team names, conference affiliations, game statistics, efficiency metrics, and postseason outcomes. The data structure is validated to ensure all required columns such as ADJOE, ADJDE, BARTHAG, POSTSEASON, and SEED are present and accessible for subsequent analyses.

Step 2: For stepwise forward selection, the 2015 dataset is filtered to include only teams with non null BARTHAG values which serves as the dependent variable representing team power rating. A candidate pool of eight predictor variables is created consisting of ADJOE, ADJDE, EFG_O, EFG_D, ORB, DRB, 3P_O, and 3P_D representing offensive and defensive metrics. The target variable BARTHAG and candidate features are extracted into separate arrays for the selection algorithm.

Step 3: The stepwise selection process initializes with an intercept only model calculating baseline mean squared error and Akaike Information Criterion. An iterative loop evaluates each remaining candidate feature by temporarily adding it to the current model, fitting linear regression, computing predictions, and calculating the resulting AIC value. This process identifies which single feature addition produces the maximum AIC reduction at each iteration step.

Step 4: The feature with the lowest AIC is selected and permanently added to the model only if the AIC improvement exceeds the threshold of two units. The selected feature is removed from the remaining candidates pool and the current AIC is updated to reflect the new model performance. This iteration continues until no remaining feature can reduce AIC by at least two units indicating optimal model parsimony.

Step 5: The final stepwise selection identifies two features ADJOE and ADJDE as statistically justified predictors of BARTHAG power rating. These represent adjusted offensive efficiency and adjusted defensive efficiency which are fundamental team performance metrics. A scatter plot matrix is generated with separate panels showing BARTHAG on y axis against each selected predictor on x axis to visualize the linear relationships.

Step 6: For tournament qualification classification, the three datasets are combined vertically using pandas concat to create a comprehensive multi year dataset. A binary target variable tournament qualified is created where value equals one if the POSTSEASON column contains any non null entry indicating tournament participation, otherwise zero for teams that did not qualify. This binary classification target will be predicted using support vector machine methodology.

Step 7: Four predictor variables are selected for SVM classification including ADJOE adjusted offensive efficiency, ADJDE adjusted defensive efficiency, WAB wins above bubble, and BARTHAG power rating. Records with missing values in any predictor or the target variable are removed to ensure complete cases for model training. The cleaned dataset contains both tournament and non tournament teams across three seasons.

Step 8: Standardization is applied to all four predictor variables using StandardScaler to transform each feature to zero mean and unit variance. This scaling is critical for support vector machines because the algorithm relies on distance calculations and unscaled features with different ranges would dominate the model. The standardized features ensure equal contribution from each predictor in the decision boundary formation.

Step 9: The dataset is partitioned into training and testing sets using a 75 to 25 split with random state 42 for reproducibility. The support vector classifier is configured with radial basis function kernel, gamma parameter 0.1 controlling kernel width, and regularization parameter C equals 10 balancing margin maximization with training error. The model is trained on the training set to learn the non linear decision boundary separating tournament and non tournament teams.

Step 10: Predictions are generated on the test set and classification accuracy is calculated as the proportion of correct predictions. The SVM achieves 93.16 percent accuracy demonstrating strong predictive performance in identifying tournament qualified teams. A decision boundary visualization is created using ADJOE and ADJDE as x and y axes showing color coded regions representing predicted tournament qualification classes.

Step 11: For DBSCAN clustering analysis, the 2014 dataset is filtered to select only teams with complete ADJOE and ADJDE values. These two efficiency metrics create a two dimensional feature space representing team performance along offensive and defensive dimensions. StandardScaler transforms both features to zero mean and unit variance creating comparable scales for distance based clustering.

Step 12: The DBSCAN algorithm is applied with epsilon neighborhood radius 0.5 and minimum samples per cluster set to 5. Epsilon defines the maximum distance for points to be considered neighbors while minimum samples determines the density threshold for core points. The algorithm identifies dense regions as clusters and isolates points in sparse regions as noise with cluster label negative one.

Step 13: After clustering assignment, the analysis counts teams assigned to the noise category indicated by cluster label negative one. Eleven teams are identified as noise points representing outliers that do not belong to any dense performance tier. A scatter plot visualizes the clustering results with standardized ADJOE on x axis and standardized ADJDE on y axis, with colors indicating cluster membership and noise points shown distinctly.

Step 14: For multinomial logistic regression, all three datasets are combined vertically to create maximum sample size for multi class classification. A conference tier categorical target is created where conferences are classified as high tier including ACC, B10, B12, SEC, and P12 power conferences, mid tier including A10, Amer, BE, MVC, and WCC mid major conferences, or low tier for all remaining conferences. This three class target will predict conference strength category from team performance metrics.

Step 15: Five predictor features are selected including W wins, ADJOE offensive efficiency, ADJDE defensive efficiency, EFG_O effective field goal percentage offense, and TOR turnover rate. Records with missing values in target or predictors are removed and the data is split into 80 percent training and 20 percent validation sets. Multinomial logistic regression is fitted with LBFGS solver and maximum iterations 1000 to ensure convergence across three conference tier classes.

Step 16: Predictions are generated on the validation set and macro averaged F1 score is calculated balancing precision and recall equally across the three tier classes. The macro F1 score of 0.6975 indicates moderate classification performance considering the challenge of predicting conference tier from team statistics. A stacked bar chart visualizes prediction distribution with true conference tier on x axis and stacked bars showing the proportion of each predicted tier within each true tier category.

Step 17: For polynomial feature analysis, ADJOE and ADJDE variables are extracted from the 2015 dataset to model non linear relationships with wins. Polynomial features of degree two are generated creating five total features including original ADJOE, original ADJDE, ADJOE squared, ADJOE times ADJDE interaction term, and ADJDE squared. This polynomial expansion captures quadratic effects and interaction between offensive and defensive efficiency.

Step 18: Linear regression is fitted using the five polynomial features to predict wins as the target variable. The model coefficient for the interaction term ADJOE times ADJDE is extracted representing the combined offensive defensive effect magnitude. The interaction coefficient value 0.0014 indicates that the multiplicative combination of offensive and defensive efficiency has a small positive effect on win prediction beyond their individual contributions.

Step 19: A three dimensional surface plot visualizes the polynomial regression model with ADJOE on x axis, ADJDE on y axis, and predicted wins on z axis. The surface shows the non linear relationship where wins depend on both efficiency metrics simultaneously. Actual team data points are overlaid on the surface as red scatter points showing model fit quality.

Step 20: For Huber regression, all three datasets are combined and win percentage is calculated as wins W divided by games G for each team. Five predictor variables are selected including BARTHAG power rating, EFG_O and EFG_D effective field goal percentages, ORB offensive rebound rate, and DRB defensive rebound rate. Huber regressor is fitted with epsilon parameter 1.35 which balances L1 and L2 loss providing robustness to outlier teams that deviate from typical performance patterns.

Step 21: Mean absolute error is calculated between predicted and actual win percentages on the full dataset measuring average prediction error magnitude. The MAE value 0.0661 indicates predictions are on average within 6.61 percentage points of actual win percentage. A residual plot is generated with predicted win percentage on x axis and residuals on y axis with horizontal line at zero showing error distribution and identifying potential outliers.

Step 22: For AdaBoost classification, all three datasets are stacked and a multi class postseason round target is created mapping POSTSEASON values to numeric codes from 0 for no tournament through 8 for Champions. Six predictor features are selected including ADJOE, ADJDE, BARTHAG, WAB, EFG_O, and EFG_D representing comprehensive team performance metrics. Records with complete target and predictors are filtered and split into 80 percent training and 20 percent validation sets.

Step 23: AdaBoost classifier is trained with 50 estimators, learning rate 1.0, and random state 42 building an ensemble of weak learners that focus on misclassified examples. Weighted accuracy is calculated on validation set where correct predictions are weighted by inverse class frequency to handle imbalanced classes since most teams do not advance far in tournaments. The weighted accuracy of 28.57 percent reflects the difficulty of predicting specific tournament round advancement from regular season statistics.

Step 24: Feature importance scores are extracted from the trained AdaBoost model quantifying each predictor's contribution to classification decisions. A bar chart visualizes the six feature names on x axis and their relative importance scores on y axis. This reveals which metrics such as BARTHAG or ADJOE are most influential in predicting postseason round advancement.

Step 25: The Spearman rank correlation analysis filters 2013 tournament teams with non null SEED values and extracts ADJ_T tempo and SEED tournament seeding variables. Spearman correlation coefficient 0.0885 is calculated measuring monotonic relationship between tempo and seed quality where lower seed numbers indicate better teams. The weak positive correlation suggests minimal relationship between playing tempo and tournament success.

Step 26: For conference win rate variance, teams are grouped by conference in 2014 data and win rate is calculated as mean of W divided by G within each conference. Conference size is counted as number of teams per conference and weighted variance is computed where each conference win rate squared deviation from grand mean is weighted by conference size. The weighted variance value 0.0052 quantifies the variability in average win rates across different conferences.

Step 27: The efficiency differential ratio analysis combines all three datasets and creates a binary tournament team indicator. Efficiency differential is calculated as ADJOE minus ADJDE representing net team performance where positive values indicate stronger offense than defense. Mean efficiency differential is computed separately for tournament teams 14.96 and non tournament teams negative 3.61 showing tournament teams have much stronger net efficiency.

Step 28: The ratio of tournament to non tournament mean efficiency differential equals negative 4.14 which appears counterintuitive but reflects that tournament teams have positive efficiency while non tournament teams have negative efficiency. The magnitude indicates tournament teams typically outperform their opponents by about 15 points per 100 possessions while non tournament teams are outscored. This efficiency gap is a strong discriminator of tournament qualification.

Step 29: The final analysis identifies the conference with maximum standard deviation of three point defense percentage 3P_D across all three combined datasets. Teams are grouped by conference and standard deviation of 3P_D is calculated within each conference measuring variability in defensive three point performance. The Pat conference exhibits maximum standard deviation 2.9623 indicating highly inconsistent three point defensive performance among teams within that conference.

Step 30: All eleven analyses produce key outputs including selected feature counts, classification accuracies, cluster noise points, F1 scores, regression coefficients, error metrics, correlations, variances, ratios, and conference identifiers. Seven visualization plots are generated including scatter matrices, decision boundaries, clustering plots, stacked bars, surface plots, residual plots, and feature importance charts. These comprehensive results provide multi dimensional insights into college basketball team performance and tournament prediction using diverse machine learning methodologies.
