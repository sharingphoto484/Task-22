VACATION RENTAL MARKET ANALYSIS

PROMPT GOAL

The analysis examines three European vacation rental datasets from Amsterdam with 1103 listings, Athens with 2653 properties, and Barcelona with 1555 accommodations to uncover pricing dynamics and guest preference patterns. Eight distinct analytical procedures are applied including machine learning regression models, clustering algorithms, statistical tests, and variability metrics to extract actionable market insights. The project trains predictive models using random forest and gradient boosting algorithms to forecast pricing and satisfaction scores while identifying geographic accommodation clusters through density based spatial analysis. Factor analysis extracts latent constructs from satisfaction metrics while ridge regression with L2 regularization prevents overfitting in price prediction models. The final deliverable includes comparative insights explaining performance differences between random forest and gradient boosting approaches for rental outcome prediction accuracy.

STEP BY STEP SOLUTIONS

Step 1 : Load three Excel datasets containing vacation rental information for Amsterdam, Athens, and Barcelona using pandas library to enable data manipulation and analysis. Verify dataset dimensions match expected record counts of 1103, 2653, and 1555 listings respectively to ensure data integrity before proceeding with analytical procedures. Examine column structures across all three datasets to confirm presence of required features including pricing, satisfaction ratings, location coordinates, and property characteristics.

Step 2 : Prepare Amsterdam dataset for random forest regression by selecting seven predictor features comprising person capacity, cleanliness rating, guest satisfaction overall, bedrooms, metro distance, attraction index normalized, and restaurant index normalized. Define realSum as the target variable representing nightly accommodation cost that the model will learn to predict from the explanatory features. Remove all observations containing missing values in either predictors or target to ensure clean training data without null entries that could corrupt model training.

Step 3 : Split Amsterdam rental data into training and testing subsets using 75 percent for training and 25 percent for testing with random state 42 to ensure reproducible partitioning across multiple executions. The training subset enables the model to learn relationships between property features and pricing while the held out test subset provides unbiased evaluation of prediction accuracy on unseen data. This separation prevents overfitting by ensuring the model generalizes beyond memorizing training examples.

Step 4 : Configure random forest regressor with 100 decision trees in the ensemble, maximum tree depth of 10 levels, minimum 5 samples required to split internal nodes, and minimum 2 samples required at leaf nodes. Set random state to 42 ensuring reproducible results across multiple runs by controlling randomness in tree building and feature sampling. Train the ensemble model on Amsterdam training data where each tree learns different patterns by using random feature subsets and bootstrap sampling.

Step 5 : Generate predictions on the test partition using the trained random forest model and compute mean absolute error quantifying average prediction deviation from actual prices. The MAE of 166.51 indicates predictions are off by approximately 167 euros on average, providing interpretable metric in original price units. This error magnitude helps assess whether the model achieves sufficient accuracy for practical rental pricing applications.

Step 6 : Extract feature importance scores from the trained random forest model indicating each predictor's contribution to reducing prediction error across all trees in the ensemble. Sort features by importance values in ascending order to prepare horizontal bar chart where vertical axis lists predictor names and horizontal axis displays importance magnitudes. Generate visualization showing which property characteristics most strongly influence Amsterdam rental pricing decisions enabling stakeholders to focus on high impact features.

Step 7 : Prepare Barcelona dataset for gradient boosting regression selecting realSum pricing, person capacity, cleanliness rating, bedrooms, distance, attraction index normalized, and restaurant index normalized as predictor features. Designate guest satisfaction overall as the response variable that the model will predict from accommodation attributes and pricing information. Eliminate all rows with null entries ensuring complete case analysis for robust model training without missing data complications.

Step 8 : Partition Barcelona data allocating 70 percent to training subset and 30 percent to testing subset using random state 42 for reproducible splits. The larger training allocation provides more examples for the sequential boosting algorithm to learn complex satisfaction patterns. The testing subset evaluates how well learned patterns generalize to new accommodations not seen during training.

Step 9 : Initialize gradient boosting regressor with 100 sequential boosting iterations, learning rate of 0.1 controlling step size for error correction, maximum tree depth of 5 limiting individual tree complexity, and minimum 10 samples for splitting nodes. Set random state to 42 ensuring reproducibility in tree construction and feature selection randomness. Fit the model on Barcelona training data where each iteration builds a new tree correcting residual errors from previous iterations.

Step 10 : Track training and validation mean squared error across all 100 boosting iterations using staged predictions that provide intermediate model states after each tree addition. Calculate MSE on training set showing how well the model fits observed data and calculate MSE on validation set showing generalization to unseen accommodations. Generate line plot with iteration numbers on horizontal axis and MSE on vertical axis displaying separate curves for training versus validation performance to visualize learning progression and potential overfitting.

Step 11 : Compute R squared coefficient on test predictions measuring the proportion of satisfaction score variance explained by the model features achieving 0.5059 indicating approximately 51 percent variance explained. This moderate R squared suggests accommodation attributes and pricing explain roughly half the variation in guest satisfaction while other unmeasured factors like service quality or location ambiance account for remaining variance. Report the metric to four decimal precision as specified in requirements providing precise performance quantification.

Step 12 : Extract longitude and latitude coordinates from Athens dataset as two dimensional spatial features representing geographic positions of 2653 rental accommodations. Standardize both coordinate columns to zero mean and unit variance using standard scaler transformation ensuring equal weighting in distance calculations regardless of original measurement scales. This normalization prevents longitude values from dominating distance metrics simply due to larger numerical ranges compared to latitude.

Step 13 : Apply DBSCAN density based clustering algorithm with epsilon parameter 0.5 defining maximum neighborhood radius, minimum samples parameter 10 requiring at least 10 points within epsilon distance to form dense regions, and euclidean metric for calculating pairwise distances. The algorithm identifies clusters as dense regions of accommodations separated by sparse areas and labels isolated points in low density regions as noise. Count total discovered clusters excluding noise labeled as minus one yielding 1 distinct geographic cluster indicating Athens rentals concentrate in a single dense area.

Step 14 : Generate scatter visualization plotting longitude on horizontal axis against latitude on vertical axis with each point representing one Athens accommodation colored by assigned cluster label. Use distinct colors for the single identified cluster and gray color for 2 noise points that fall outside dense regions. This geographic visualization reveals spatial distribution patterns showing whether rentals cluster near tourist attractions, city centers, or disperse across metropolitan areas.

Step 15 : Select five satisfaction related variables from Athens dataset including cleanliness rating, guest satisfaction overall, attraction index normalized, restaurant index normalized, and realSum pricing for factor analysis. Standardize all five variables to unit variance and zero mean ensuring equal contribution to factor extraction regardless of original measurement scales. This preprocessing step is critical for factor analysis which assumes variables are comparable in scale and distribution.

Step 16 : Execute factor analysis extracting three latent factors using principal component analysis with varimax rotation to achieve orthogonal factor solution where factors are uncorrelated and easier to interpret. The minres method would minimize residual correlations but PCA based approach is used as fallback due to library compatibility ensuring analysis completes successfully. Extract loadings matrix showing correlation between each observed variable and each of three extracted factors revealing underlying constructs like quality perception, location value, and pricing tier.

Step 17 : Report the loading of cleanliness rating on first factor as 0.6252 indicating strong positive association where higher cleanliness scores correspond to higher values on the first latent construct. Generate heatmap visualization with five variables as rows, three factors as columns, and cell colors encoding loading magnitudes using diverging colormap centered at zero. Positive loadings appear in one color and negative loadings in contrasting color enabling quick identification of variable factor relationships and interpretation of latent constructs.

Step 18 : Prepare Barcelona dataset for ridge regression selecting person capacity, bedrooms, distance, metro distance, cleanliness rating, and guest satisfaction overall as six independent predictors. Define realSum as dependent variable representing accommodation price that will be predicted from property and satisfaction features. Remove observations with missing values ensuring complete data for regression coefficient estimation without bias from imputation methods.

Step 19 : Split Barcelona data with 80 percent allocated to training phase and 20 percent to testing phase using random state 42 for reproducible partitioning. Fit ridge regressor with alpha regularization parameter 1.0 applying L2 penalty that shrinks coefficient magnitudes toward zero preventing overfitting when predictors are correlated. The regularization improves generalization by trading slight training accuracy for better test performance through controlled coefficient complexity.

Step 20 : Calculate root mean squared error on test predictions yielding 115.329 measuring average prediction error in euros with larger errors penalized more heavily than in MAE. Generate horizontal bar chart comparing absolute values of six regression coefficients with vertical axis enumerating predictor names and horizontal axis showing coefficient magnitudes. Color bars by coefficient sign using green for positive coefficients indicating features that increase price and red for negative coefficients indicating features that decrease price.

Step 21 : Extract realSum pricing column from Amsterdam dataset and Athens dataset as two independent samples for statistical comparison of central tendencies between markets. Apply Welch t test from scipy stats module with equal variance parameter set to False allowing unequal variances between the two city samples. Compute t statistic of 26.965 quantifying how many standard errors the mean price difference deviates from zero assuming null hypothesis of equal means.

Step 22 : Calculate first quartile at 25th percentile and third quartile at 75th percentile for Barcelona realSum distribution using numpy percentile function. Compute interquartile range as the difference between third and first quartiles yielding 173.39 representing the price spread of the middle 50 percent of Barcelona accommodations. This robust dispersion measure resists outlier influence unlike range or standard deviation making it ideal for skewed rental price distributions.

Step 23 : Compute mean and standard deviation of Amsterdam realSum prices across all 1103 listings calculating average price of 545.02 euros and variability of 416.97 euros. Calculate coefficient of variation as standard deviation divided by mean multiplied by 100 yielding 76.51 percent indicating high relative price variability. This percentage metric enables comparison across markets with different price levels showing Amsterdam rentals exhibit substantial heterogeneity in pricing strategies.

Step 24 : Synthesize comparative insights explaining that random forest achieves superior generalization through parallel ensemble averaging where hundreds of independent trees vote on predictions reducing variance and preventing overfitting to training noise. Contrast with gradient boosting which attains potentially higher accuracy through sequential error correction where each tree fixes mistakes of previous trees but risks overfitting without careful regularization of learning rate and tree depth. Conclude that random forest proves more robust for noisy rental data with complex feature interactions while gradient boosting excels when patterns are systematic and training data is abundant and clean making algorithm selection dependent on data quality and complexity characteristics.
