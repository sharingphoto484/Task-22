QC NOTES FOR BLINKIT DELIVERY OPTIMIZATION ANALYSIS

PROMPT GOAL

The analysis aims to implement advanced machine learning techniques on three Blinkit datasets containing customer demographics, feedback records, and delivery performance metrics to optimize delivery efficiency and predict customer behavior patterns. The project requires twelve distinct analytical tasks including ridge regression with cross validation for order value prediction, lasso regression for feature selection in rating prediction, support vector regression for non linear delivery time modeling, exponential smoothing for time series forecasting, and logistic regression for binary classification of high ratings. Statistical analyses include chi square test for independence, z score normalization for outlier detection, median absolute deviation calculation, interquartile range ratio comparison, variance inflation factor for multicollinearity detection, baseline RMSE calculation, and F statistic for variance equality testing. Each analysis must produce specific numerical outputs rounded to required decimal places along with corresponding visualizations including line plots, bar charts, scatter plots, and ROC curves. The final deliverable includes an assessment of which modeling approach optimizes prediction performance based on ridge regularization strength versus lasso feature selection capabilities.

STEP BY STEP SOLUTIONS

Step 1: The analysis begins by loading three Excel files representing customers with demographic and transaction data, customer feedback with ratings and sentiment classifications, and delivery performance with timing metrics. All datasets are imported using pandas library and date columns are converted to datetime format for temporal calculations. The initial data exploration confirms 2500 customer records, 5000 feedback entries, and 5000 delivery performance records are available for analysis.

Step 2: For ridge regression analysis, account age in months is calculated by finding the difference between the reference date of December twentieth twenty twenty four and each customer registration date then converting days to months. This temporal feature captures customer tenure which influences purchasing behavior and order value patterns. The calculation uses 30.44 days per month for accurate monthly conversion.

Step 3: Pincode variance is engineered by extracting the first three digits of each customer pincode to create geographic clusters then calculating the standard deviation of average order values within each cluster. This variance metric is mapped back to individual customers representing the volatility of spending patterns in their geographic area. Areas with higher variance indicate diverse customer spending behaviors while lower variance suggests homogeneous customer segments.

Step 4: Three predictor variables including total orders representing purchase frequency, account age months capturing tenure, and pincode variance reflecting geographic spending patterns are selected along with the target variable average order value. All records with complete data for these four variables are retained ensuring no missing values compromise the regression analysis. The features are standardized to zero mean and unit variance to ensure equal contribution during regularized regression.

Step 5: Ridge regression cross validation tests fifty alpha values ranging from 0.01 to 100 on a logarithmic scale using five fold cross validation to identify the optimal regularization strength. Each alpha value is evaluated by fitting ridge models and calculating mean squared error across validation folds. The alpha producing minimum cross validated MSE represents the best bias variance tradeoff for this prediction task.

Step 6: The optimal alpha of 100.0 indicates strong regularization is needed suggesting multicollinearity among predictors or need to prevent overfitting on training data. With this optimal alpha, the ridge model is fitted on the full standardized dataset and the coefficient for total orders predictor is extracted. The coefficient of 7.4689 indicates that for each standard deviation increase in total orders, the average order value increases by approximately 7.47 dollars after accounting for regularization.

Step 7: A line plot visualizes the relationship between log scaled alpha values on x axis and mean squared error on y axis showing how prediction error changes with regularization strength. The plot includes a vertical red dashed line marking the optimal alpha where MSE is minimized. This visualization helps understand the regularization tradeoff where too little regularization causes overfitting and too much causes underfitting.

Step 8: For lasso regression analysis, binary dummy variables are created from the feedback category column generating four separate indicator variables for Delivery, App Experience, Customer Service, and Product Quality categories. Sentiment strength is numerically encoded by mapping Positive to 2, Neutral to 1, and Negative to 0 creating an ordinal feature. Feedback month is extracted from the feedback date to capture seasonal patterns in customer ratings.

Step 9: Six predictor features including four category dummies, sentiment strength, and feedback month are combined with the rating target variable and standardized to zero mean unit variance. Lasso regression with alpha parameter of 0.1 applies L1 penalty encouraging sparse solutions where irrelevant features have coefficients shrunk exactly to zero. This automatic feature selection identifies which predictors genuinely influence customer ratings.

Step 10: The fitted lasso model produces only 1 non zero coefficient out of 6 total features indicating extreme sparsity where only one predictor survives the regularization penalty. This suggests most features do not provide unique predictive information for ratings after accounting for the selected feature. The bar chart displays absolute coefficient values for all six features showing which variables were selected versus eliminated.

Step 11: Support vector regression is applied to predict delivery time in minutes using distance in kilometers and hour of day extracted from promised time as predictors. Only delivery records with times between negative 5 and 30 minutes are retained ensuring valid observations within reasonable delivery windows. The two predictors are standardized before fitting SVR with radial basis function kernel using gamma of 0.1, C parameter of 1.0, and epsilon of 0.1.

Step 12: The RBF kernel enables SVR to capture non linear relationships between delivery time and the predictors such as rush hour effects or distance based complexity. After training on 80 percent of data, predictions are generated for the validation set of 20 percent. Mean absolute percentage error of 115.43 percent indicates poor prediction accuracy likely due to high variability in delivery times not captured by just distance and hour features.

Step 13: A scatter plot displays actual delivery times on x axis versus predicted delivery times on y axis with a diagonal red line representing perfect predictions. Points scattered far from this diagonal reveal systematic prediction errors where the model struggles to match actual performance. This visualization exposes the limitations of using only two features for complex delivery time prediction.

Step 14: Exponential smoothing forecasts daily order volumes by first aggregating delivery data to count total orders per date creating a time series. The data is sorted chronologically and split into 80 percent training period covering 480 days and 20 percent test period covering 120 days. Simple exponential smoothing with alpha of 0.3 weights recent observations more heavily while incorporating historical patterns.

Step 15: The smoothing formula recursively updates forecasts where each new forecast equals 0.3 times the previous actual value plus 0.7 times the previous forecast creating adaptive predictions. Starting with the training mean as initial forecast, predictions are generated for all test period dates. Root mean squared error of 3.35 between forecasted and actual order counts indicates relatively accurate daily volume predictions with errors averaging about 3 orders per day.

Step 16: The time series plot shows training actual values in blue, test actual values in green, and forecasts in red dashed line across dates on x axis with order counts on y axis. Visual inspection reveals how well the smoothed forecasts track actual fluctuations in daily order volumes. The relatively close alignment between forecast and actual lines in the test period confirms the RMSE finding of good prediction accuracy.

Step 17: Logistic regression for high rating classification requires merging feedback and delivery datasets on order ID to combine rating information with delivery performance metrics. A binary target is created where high rating equals 1 if rating is 4 or 5 stars otherwise 0. Three predictor features are engineered including on time delivery indicator, delivery speed category for deliveries under 5 minutes, and positive sentiment indicator.

Step 18: The logistic regression model is fitted with random state 42 for reproducibility and probability scores are generated for each observation. ROC curve analysis plots true positive rate versus false positive rate across all possible probability thresholds. The optimal threshold of 0.2934 is identified where sensitivity equals specificity representing balanced classification performance.

Step 19: At this optimal threshold, true positive rate of 0.6696 means 67 percent of actual high ratings are correctly identified while false positive rate of 0.0687 means only 7 percent of low ratings are misclassified. The ROC curve plot shows model performance significantly better than random classification diagonal line. A red dot marks the optimal operating point for balanced sensitivity and specificity.

Step 20: Chi square test examines independence between feedback category and sentiment by creating a contingency table with categories as rows and sentiments as columns. The chi square statistic of 4.48 with p value of 0.61 indicates no significant association between which category customers comment on and whether their sentiment is positive, neutral, or negative. This suggests feedback sentiment is distributed similarly across all service categories.

Step 21: Z score normalization calculates standardized scores for each customer average order value by subtracting the mean of 1102.38 dollars and dividing by standard deviation of 523.04 dollars. Outliers are identified as observations where absolute z score exceeds 3 representing values more than three standard deviations from the mean. Zero outliers found indicates the order value distribution lacks extreme values and follows a relatively normal pattern without anomalous customers.

Step 22: Median absolute deviation provides a robust measure of delivery time variability less sensitive to outliers than standard deviation. The median delivery time of 2 minutes serves as the center and absolute deviations from this median are calculated for each delivery. The median of these deviations multiplied by 1.4826 constant yields MAD of 5.93 indicating typical delivery time variations of approximately 6 minutes from the median.

Step 23: Interquartile range ratio compares dispersion between Premium and New customer segments by calculating IQR as the difference between third quartile Q3 and first quartile Q1 of total orders for each segment. Premium segment IQR of 10 and New segment IQR of 10 produce a ratio of 1.00 indicating both segments have identical spread in order frequency. This equal dispersion suggests similar variability in purchasing patterns regardless of customer segment classification.

Step 24: Variance inflation factor detects multicollinearity by merging delivery and customer datasets then selecting three numeric features including distance, total orders, and average order value. For each feature, a linear regression is fitted using the other two features as predictors and R squared is calculated. VIF equals 1 divided by 1 minus R squared where values above 5 or 10 indicate problematic multicollinearity but the maximum VIF of 1.00 shows these features are completely independent with no correlation issues.

Step 25: Baseline RMSE establishes prediction accuracy using the simplest possible model where all test observations are predicted as the training data mean delivery time of 4.46 minutes. Squared differences between actual test values and this constant prediction are calculated and averaged then square rooted. The baseline RMSE of 7.90 minutes provides a benchmark that any sophisticated model should outperform to demonstrate added value beyond naive mean prediction.

Step 26: F statistic tests variance equality between Premium and Regular customer segments for average order values with Premium segment having 633 customers averaging 1101.47 dollars and Regular segment having 639 customers averaging 1089.47 dollars. Between group variance captures differences in segment means while within group variance pools variability within each segment. The F statistic of 0.17 is very low indicating the variance between segment means is much smaller than variance within segments suggesting no significant difference in order value dispersion across these customer types.

MODELING APPROACH RECOMMENDATION

Ridge regression with optimal alpha of 100 demonstrates that strong L2 regularization is necessary for this prediction task balancing bias and variance by shrinking coefficients proportionally without eliminating any features entirely. The ridge coefficient of 7.4689 for total orders remains substantial even with heavy regularization indicating this predictor has robust predictive power for average order value. In contrast, lasso regression produces extreme sparsity with only 1 of 6 features surviving the L1 penalty suggesting most predictors provide redundant information once the key feature is included.

The fundamental difference lies in how regularization penalties operate where ridge L2 penalty shrinks all coefficients toward zero but rarely to exactly zero maintaining all features with reduced weights. Lasso L1 penalty creates sparse solutions by driving less important coefficients to exactly zero performing automatic feature selection and producing interpretable models with fewer variables. For scenarios requiring all features due to multicollinearity or when coefficients should be small but non zero, ridge regression excels by stabilizing estimates without excluding potentially relevant predictors.

When interpretability is critical and many features may be irrelevant or redundant, lasso superior performance emerges through automatic selection of the most influential predictors eliminating noise variables entirely. The choice between approaches depends on whether the goal prioritizes prediction accuracy with all available information favoring ridge or model simplicity and feature identification favoring lasso. In this Blinkit analysis, lasso aggressive selection down to one feature suggests significant redundancy in the rating predictors while ridge retention of all order value predictors indicates each contributes unique though correlated information requiring regularization to prevent overfitting.
