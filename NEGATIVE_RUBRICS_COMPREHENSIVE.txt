## Failure Ideas Repository: Airline Operations Analysis

### Failure Idea 1: Train-Test Split Contamination in Performance Metrics

**Failure Idea:** The analyst reports SVM classification accuracy of 85.04 percent and decision tree accuracy of 85.05 percent, suggesting these models were trained and evaluated using identical random state 42 splits. However, these values deviate from the correctly computed metrics (85.43% and 85.40% respectively), indicating the train-test split was not executed with proper reproducibility controls or the evaluation was performed on a contaminated test set. This type of error commonly arises when random state parameters are inconsistently applied across split operations, when data preprocessing steps occur in different orders before splitting, or when observations are inadvertently duplicated or dropped during the dropna operations. The consequence is that reported performance metrics do not reflect true held-out generalization capability, making model comparison unreliable and potentially leading to overconfident deployment decisions based on inflated or deflated accuracy estimates.

**Corresponding Rubric Item:**
- **Reports that the SVM classification accuracy is 85.04 percent instead of 85.43 percent.**
- **-20 points · must have criteria**

### Failure Idea 2: Macro F1 Score Miscomputation from Imbalanced Class Predictions

**Failure Idea:** The analyst reports SVM macro F1 score of 0.4596 when the correct value is 0.4607, a discrepancy of 0.0011 that suggests improper averaging of class-specific F1 scores. Macro F1 requires computing precision and recall separately for each class (booking complete vs non-complete), then averaging these F1 scores without weighting by class frequency. This error pattern typically emerges when the averaging method parameter is set incorrectly (weighted instead of macro), when the confusion matrix used for calculation contains wrong cell values due to prediction errors, or when class labels are inconsistently encoded during evaluation. Since the prompt specifically requires macro F1 to assess balanced classification performance across both majority and minority classes, this computational error directly undermines the ability to compare how well SVM and decision tree handle class imbalance, which is the central analytical question posed by the prompt.

**Corresponding Rubric Item:**
- **Reports that the SVM macro F1 score is 0.4596 instead of 0.4607.**
- **-20 points · must have criteria**

### Failure Idea 4: OneVsRestClassifier Wrapper Omission in Multiclass ROC Analysis

**Failure Idea:** The analyst reports K-NN per-class ROC AUC scores of 0.5111 for CircleTrip, 0.5147 for OneWay, and 0.5179 for RoundTrip, deviating from correct values of 0.5202, 0.5210, and 0.5265 respectively. These consistent underestimations across all three trip types suggest the KNeighborsClassifier was not properly wrapped in OneVsRestClassifier as explicitly required by the prompt. Without this wrapper, the predict_proba method produces different probability estimates because the multiclass decomposition structure changes from one-versus-rest to one-versus-one or uses the default sklearn multiclass handling. The OneVsRestClassifier wrapper is essential for ROC analysis because it explicitly decomposes the three-class problem into three binary classification tasks (CircleTrip vs others, OneWay vs others, RoundTrip vs others), enabling proper calculation of true positive rates and false positive rates for each class independently. Omitting this wrapper produces incomparable AUC values that appear valid superficially but cannot be correctly interpreted under the one-versus-rest framework specified in the prompt.

**Corresponding Rubric Item:**
- **Reports that the CircleTrip ROC AUC score is 0.5111 instead of 0.5202.**
- **-20 points · must have criteria**

### Failure Idea 5: Bootstrap Resampling Non-Determinism in Mediation Confidence Intervals

**Failure Idea:** The analyst fails to report actual computed values for the mediation analysis indirect effect, instead providing placeholder text such as "expected to include 0" for the 95 percent bootstrap confidence interval. This pattern indicates the bootstrap resampling procedure was either not executed or not executed with the required deterministic RandomState(42) seed. Proper mediation analysis requires 1000 bootstrap replications where each iteration samples row indices with replacement, refits both the X→M and M→Y logistic regression models, computes the product a×b, and stores this indirect effect estimate. The percentile method then extracts the 2.5th and 97.5th percentiles from this distribution to form the confidence interval. Without executing this procedure with fixed random seed, it is impossible to determine whether the confidence interval excludes zero, which is the sole criterion specified in the prompt for concluding statistical mediation support. The absence of computed values suggests computational difficulty with 1000 logistic regression fits or misunderstanding of the bootstrap percentile method, both of which prevent valid inference about whether meal service preference mediates the purchase lead to booking completion pathway.

**Corresponding Rubric Item:**
- **Fails to report the actual computed 95 percent bootstrap confidence interval for the indirect effect.**
- **-25 points · must have criteria**

When translated to probability scale, this corresponds to a change of less than 0.002 percentage points in booking probability. The analyst should explicitly state that while mediation is statistically detectable, the practical business implication is that meal service preference is an ineffective lever for converting advance bookers into completed reservations.

### Failure Idea 10: Decision Tree Feature Importance as Causal Drivers

**Failure Idea:** The analyst reports decision tree feature importance scores showing length_of_stay (0.4546) and wants_extra_baggage (0.3348) as dominant features and interprets these as "driving" booking completion or as levers for improving conversion rates. This reasoning conflates predictive association measured by Gini importance with causal effect or actionable business intervention. Feature importance in decision trees measures how much each variable reduces node impurity during recursive partitioning, which depends on correlation structure, feature availability at each split, and the sequential order of splits. High importance for length_of_stay does not establish that encouraging longer stays will increase booking completion - it only indicates that observations with longer planned stays are more likely to complete bookings in this observational dataset. The association could arise because customers who have already decided to book (unobserved commitment) then search for longer stays, making length_of_stay a consequence rather than cause of booking intent. Similarly, wants_extra_baggage might proxy for business travelers or trip seriousness rather than being a causally manipulable feature. Using these feature importances to design interventions (e.g., "promote longer stays" or "incentivize baggage add-ons") requires causal assumptions that cannot be validated from this cross-sectional observational data with decision tree splits.

**Corresponding Rubric Item:**
- **Interprets decision tree feature importance scores as causal drivers of booking completion that can be directly manipulated to improve conversion rates.**
- **-12 points · nice to have criteria**

**Failure Idea:** The analyst fails to report the actual RMSE value (1.471) for flight duration prediction and instead uses placeholder notation. Beyond this computational failure, a deeper conceptual error would be interpreting any RMSE value as certification of prediction quality without examining the residual plot structure or considering the scale of the dependent variable. The prompt requests the residual plot precisely to assess specification adequacy, not to celebrate low RMSE as proof of model validity.
