PROMPT GOAL

The analysis requires standardizing three stock CSV files containing EICHERMOT, HCLTECH, and BPCL data to ensure each has exactly Date, Open, High, Low, Close, and Volume columns with proper spelling. The data must be restricted to the exact daily intersection across all three files to maintain temporal alignment, treating the data as daily frequency with returns computed as the first difference of natural log of Close prices. The system estimates long run cointegrating relations using the Johansen procedure with Schwarz criterion lag selection from one to five lags, selecting rank via the five percent trace test, and fitting a vector error correction model to measure adjustment speeds when cointegration is detected. Volatility dynamics are modeled using two state Gaussian Markov switching specifications to identify high volatility regimes with expected durations and stationary probabilities, while Rogers Satchell variance provides a robust annualized volatility measure using daily High Low Open Close data. Additional analyses include testing day of week seasonality via ANOVA, constructing rolling seasonality heatmaps over twenty four month windows with two hundred fifty two day lookbacks, and assessing drift in equal weight portfolio returns using Newey West heteroscedasticity and autocorrelation consistent standard errors at lag five. All outputs are restricted to key numeric results reported at four decimal precision for continuous measures and integer counts for categorical results, with zero values assigned by rule when sample sizes fall below required windows or when conditions like zero cointegration rank apply.


STEP BY STEP SOLUTION

Step 1 : Data Loading and Column Standardization
The script begins by loading each of the three CSV files and extracting only the required columns which are Date, Open, High, Low, Close, and Volume, discarding all other columns present in the raw data such as Symbol, Series, Prev Close, VWAP, Turnover, and others. Each column is converted to the appropriate data type with Date parsed as datetime objects and all price and volume fields converted to numeric values with errors coerced to missing values. The Date column is set as the index for each dataframe after sorting chronologically, and duplicate dates are handled by keeping only the last occurrence of each date per the prompt requirement.

Step 2 : Exact Daily Intersection Formation
After standardizing all three files separately, the script computes the exact set of dates that appear in all three dataframes simultaneously using pandas index intersection operations applied sequentially. This intersection produces a common date range of five thousand two hundred ninety five trading days where all three stocks have valid data available. Each of the three dataframes is then filtered to retain only rows corresponding to these common dates, ensuring perfect temporal alignment across all subsequent calculations and eliminating any missing value issues from mismatched dates.

Step 3 : Log Returns Calculation
For each ticker, the natural logarithm of the Close price is computed to create a LogClose column, and the return series is generated as the first difference of this log price series. This transformation converts price levels into continuously compounded returns which have better statistical properties for modeling including approximate normality and stationarity. The first row of each dataframe containing a missing return value due to the differencing operation is removed, leaving five thousand two hundred ninety four valid return observations per ticker for all downstream analyses.

Step 4 : Johansen Cointegration Test with Lag Selection
The cointegration analysis constructs a matrix of log prices for the three tickers and tests for long run equilibrium relationships using the Johansen procedure with a constant term in the cointegrating relation. Lag selection is performed by iterating over lag orders from one through five and computing an approximate Bayesian Information Criterion for each, selecting the lag that minimizes this criterion to balance fit quality against model complexity. The Johansen trace test statistics are compared against five percent critical values sequentially to determine the cointegration rank, which represents the number of independent long run relationships linking the three price series.

Step 5 : Vector Error Correction Model Estimation
When the cointegration rank is determined to be greater than zero, indicating at least one long run relationship exists, a vector error correction model is estimated using the selected lag and rank parameters. The alpha coefficients from this model represent adjustment speeds, measuring how quickly each stock price corrects deviations from the long run equilibrium relationship. Statistical significance of negative adjustment speeds is assessed by computing t statistics as the ratio of each alpha coefficient to its standard error and comparing against a critical value of negative one point six four five for a one sided five percent test.

Step 6 : Markov Switching Volatility Models
For each ticker separately, a two state Gaussian Markov switching model is fitted to the return series with state dependent variance parameters and a constant term, using maximum likelihood estimation with Kim smoothing for state probability inference. The high volatility state is identified as whichever of the two states exhibits the larger estimated variance parameter. Expected duration in the high volatility state is calculated as one divided by one minus the probability of remaining in that state, while stationary probability is derived from the transition matrix by computing the ratio of off diagonal transition probabilities.

Step 7 : Rogers Satchell Volatility Estimation
The Rogers Satchell estimator computes daily variance without requiring zero drift assumptions by using the formula that combines log ratios of High to Close, High to Open, Low to Close, and Low to Open within each trading day. A thirty day rolling window average of these daily variance estimates is computed to smooth short term fluctuations and provide a more stable volatility measure. The rolling variance series is then annualized by multiplying by two hundred fifty two trading days per year and taking the square root to convert variance to volatility, and the median of this annualized series is taken for each ticker before averaging across the three stocks.

Step 8 : Day of Week Seasonality Testing
Returns from all three tickers are combined into a single pooled dataset with each observation tagged by its day of week identifier ranging from zero for Monday through four for Friday. A one way analysis of variance is performed with day of week as the grouping factor to test the null hypothesis that mean returns are equal across all weekdays against the alternative that at least one day has a different mean return. The p value from this F test is compared to the five percent significance threshold, and a binary indicator is set to one if significant seasonality is detected or zero otherwise.

Step 9 : Rolling Seasonality Heatmap Construction
The heatmap analysis identifies the most recent twenty four calendar months within the common date range and iterates over each month and day of week combination. For each cell in this month by weekday grid, the script looks backward from that month end to gather the preceding two hundred fifty two trading days of return data. The median return in percentage terms is computed for observations matching that specific weekday within the lookback window, and the maximum value across all cells in the heatmap is identified and reported as the peak seasonal effect.

Step 10 : Drift Assessment with Newey West Standard Errors
An equal weighted portfolio return is constructed by averaging the three ticker returns at each date, and the sample mean of this portfolio return series is computed. To test whether this mean is significantly positive, ordinary least squares regression is performed with the portfolio returns as the dependent variable and only a constant term as the independent variable, using heteroscedasticity and autocorrelation consistent covariance estimation with a maximum lag of five periods following the Newey West method. The t statistic from this regression is used to compute a one sided p value testing the null hypothesis that the mean is zero against the alternative that it is positive, and a binary indicator equals one only if both the point estimate is positive and the p value falls below five percent.
