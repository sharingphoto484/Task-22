URBAN AIR QUALITY ANALYSIS PROJECT

PROMPT GOAL

The objective is to perform comprehensive atmospheric monitoring analysis across three major cities Sydney New York and London using twelve distinct machine learning methodologies on hourly air quality measurements. Each dataset contains 8760 hourly observations with variables including Date City CO NO2 SO2 O3 PM2.5 PM10 and AQI requiring predictive modeling classification regression clustering and dimensionality reduction techniques. The analysis demands specific train test splits ranging from 70-30 to 80-20 with consistent random state 42 for reproducibility alongside precise model hyperparameters for RandomForest GradientBoosting XGBoost AdaBoost PLS Ridge Lasso ElasticNet SVR KMeans and PCA algorithms. All outputs require exact decimal precision ranging from two to four decimal places with corresponding visualizations including horizontal bar charts confusion matrices scatter plots residual plots and ROC curves. The final deliverable includes a comparative analysis between XGBoost sequential residual fitting and RandomForest bootstrap aggregation to determine optimal ensemble methodology for air quality prediction.

The cleaned dataset separates into feature matrix X containing all six pollutant predictors and target vector y containing AQI values creating the foundation for supervised learning.

Step 3 : Sydney Random Forest Train Test Partitioning

The prepared Sydney data splits into training and testing subsets using 75 percent for training and 25 percent for testing with random state 42 ensuring reproducible random sampling. This stratified division creates four distinct arrays including X train rf X test rf y train rf and y test rf maintaining proportional representation of the original dataset distribution. The 75-25 split balances model learning capacity with adequate holdout data for unbiased performance evaluation allowing sufficient training examples while preserving test set integrity.

Step 4 : Sydney Random Forest Model Training

RandomForestRegressor instantiates with specific hyperparameters including 100 estimators representing individual decision trees max depth 10 limiting tree growth to prevent overfitting and min samples split 5 requiring minimum samples for node splitting. Step 5 : Sydney Random Forest Performance Evaluation

Predictions generate on the holdout test set using the trained Random Forest model producing continuous AQI forecasts for comparison against actual observed values. Root mean squared error calculation measures prediction accuracy by computing the square root of averaged squared differences between predicted and actual AQI values. The resulting RMSE of 4.04 indicates relatively low prediction error demonstrating strong model performance with predictions deviating approximately 4 AQI units from true values on average.

Feature importance scores extract from the trained model quantifying each predictor variable contribution to AQI prediction accuracy based on mean decrease in impurity across all decision trees. The New York dataset transforms the continuous AQI variable into a three level categorical target representing air quality categories good moderate and poor. Category boundaries define good as AQI below 35 moderate spanning 35 through 55 and poor exceeding 55 using pandas cut function for binning continuous values. This discretization converts the regression problem into a multiclass classification task enabling categorical prediction algorithms to learn decision boundaries separating distinct air quality states.

Partial Least Squares regression addresses PM10 prediction using five predictor variables CO NO2 SO2 O3 and PM2.5 through latent variable extraction maximizing covariance between predictors and response.
