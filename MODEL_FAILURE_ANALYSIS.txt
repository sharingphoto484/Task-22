MODEL FAILURE ANALYSIS - INCORRECT QUANTITATIVE OUTPUTS

GAMMA GLM DISCOUNT COEFFICIENT ERROR

The model reported negative 1.6412 for the Gamma GLM discount coefficient, but the correct value is positive 0.0011, likely because the model used an incorrect link function specification or failed to properly construct the design matrix with an intercept term. Gamma family generalized linear models require careful handling of strictly positive response variables and the canonical log link, which when misspecified can produce coefficient estimates with reversed signs and inflated magnitudes. The other model may have also failed to filter out non-positive extended values or missing discount entries before fitting, leading to convergence issues that produced numerically unstable parameter estimates that do not reflect the true weak positive relationship between discount and extended value.

MDS STRESS VALUE ERROR

The model reported 0.0000 for the MDS stress value of the two-dimensional customer-location embedding, but the correct value is 2.3870, likely because the model applied MDS to a smaller subset of customers or used metric MDS on the raw encoded state values rather than on the precomputed dissimilarity matrix. A stress value of exactly zero indicates perfect embedding which is mathematically implausible when projecting higher-dimensional discrete state encodings into two dimensions, suggesting the model either worked with trivially few unique states or incorrectly initialized the MDS algorithm. The true stress of 2.3870 reflects the expected distortion when compressing the pairwise distance structure of 1445 customers across multiple encoded state values into a low-dimensional Euclidean space, and achieving zero stress would require the original data to already lie perfectly in two dimensions.

MONTHLY DEVIATION STANDARD DEVIATION ERROR

The model reported 0.176 for the standard deviation of monthly mean fulfillment deviations, but the correct value is 0.165, likely because the model computed deviations using a different date pairing such as order_date minus required_date instead of shipped_date minus required_date, or failed to properly group observations by calendar month using period extraction. Small numerical discrepancies in temporal aggregation can arise from timezone handling, partial month inclusion at dataset boundaries, or different methods of computing the month identifier from datetime objects. The model may have also included months with insufficient observations or failed to drop rows where either required_date or shipped_date was missing, introducing additional variance into the monthly mean calculations that inflated the overall standard deviation estimate.

STATIONARY PROBABILITY ERROR

The model reported 0.869 for the highest stationary probability in the order status Markov chain, but the correct value is 0.895, likely because the model built the transition matrix using different state encoding or failed to properly normalize the transition frequencies into valid probability distributions before computing the stationary distribution. The eigenvalue decomposition method for finding stationary distributions is sensitive to numerical precision and the choice of which eigenvector corresponds to the unit eigenvalue, and slight errors in transition matrix construction or incorrect handling of absorbing states can shift the stationary probabilities. The other model may have also used a different Markov order or incorrectly aggregated transitions across status categories, resulting in a transition structure that underestimates the concentration of long-run probability mass in the dominant absorbing state that characterizes completed order status.
